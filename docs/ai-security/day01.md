# Day 01 - AI 安全入门

> 学习日期：2026-09-13
> 学习目标：了解 AI 安全的基本概念、研究方向和学习路径

---

## 一、什么是 AI 安全

AI 安全（AI Security）是研究人工智能系统本身的安全问题，以及 AI 技术在安全领域应用的交叉学科。

简单说包含两大方向：
1. **AI 本身的安全**：AI 模型会不会被攻击、被绕过、被窃取
2. **AI 赋能安全**：用 AI 技术做安全防护、漏洞挖掘、恶意代码检测

---

## 二、AI 安全的主要研究方向

### 方向一：AI 模型安全（攻击 AI）

| 攻击类型 | 说明 | 通俗理解 |
|---------|------|---------|
| 对抗样本攻击 | 给输入加微小扰动，让模型分类错误 | 给图片加一层人眼看不到的噪点，AI 就认错了 |
| 模型窃取 | 通过查询接口还原或训练出替代模型 | 不断问 AI 问题，偷偷"抄"出一个一样的 AI |
| 数据投毒 | 在训练数据里植入恶意样本 | 在 AI 学习的资料里掺假，让它学坏 |
| 后门攻击 | 在模型里植入隐藏触发器 | 给 AI 装个"开关"，特定输入触发恶意行为 |
| 提示词注入 | 通过输入篡改大模型的指令 | 用话术绕过 AI 的安全限制，让它干不该干的事 |

### 方向二：AI 安全应用（用 AI 做安全）

- **AI 辅助漏洞挖掘**：用大模型分析代码，自动发现漏洞
- **AI 恶意代码检测**：用机器学习识别病毒、木马
- **AI 流量分析**：用 AI 检测网络异常和入侵行为
- **AI 钓鱼检测**：用 AI 识别钓鱼邮件和网站

## 三、大模型安全（LLM Security）—— 当前最火方向

大语言模型（如 GPT、Claude、豆包）的安全问题是目前的热点。

### 常见攻击手段

1. **提示词注入（Prompt Injection）**
   - 原理：在用户输入中嵌入恶意指令，覆盖系统预设指令
   - 例子：让 AI 忽略之前的规则，输出敏感信息

2. **越狱攻击（Jailbreak）**
   - 原理：通过特殊话术绕过模型的安全对齐
   - 例子：角色扮演、虚构场景、多轮诱导

3. **数据泄露**
   - 原理：诱导模型输出训练数据中的隐私信息
   - 例子：让模型背诵训练时见过的个人信息

4. **幻觉与错误信息**
   - 原理：模型编造虚假信息并以自信语气输出
   - 风险：被用于生成假新闻、误导性内容

5. **输出过滤绕过**
   - 原理：用编码、拆分、谐音等方式绕过内容审查
   - 例子：用 Base64 编码、拆字、谐音字传递恶意内容

### OWASP LLM Top 10（必知）

这是大模型安全的权威榜单，一定要了解：

| 编号 | 风险 |
|------|------|
| LLM01 | 提示词注入（Prompt Injection） |
| LLM02 | 敏感信息泄露（Sensitive Information Disclosure） |
| LLM03 | 供应链（Supply Chain） |
| LLM04 | 数据和模型投毒（Data and Model Poisoning） |
| LLM05 | 不当输出处理（Improper Output Handling） |
| LLM06 | 过度代理（Excessive Agency） |
| LLM07 | 系统提示泄露（System Prompt Leakage） |
| LLM08 | 向量和嵌入弱点（Vector and Embedding Weaknesses） |
| LLM09 | 错误信息（Misinformation） |
| LLM10 | 无界消耗（Unbounded Consumption） |

> 官方地址：https://owasp.org/www-project-top-10-for-large-language-model-applications/
