# 漏洞赏金入门

## 一、什么是 Bug Bounty

漏洞赏金（Bug Bounty）是企业或组织通过奖励计划，邀请安全研究者发现并报告其系统中的安全漏洞。

## 二、知名平台

- **HackerOne**：全球最大的漏洞赏金平台
- **Bugcrowd**：另一个主流平台
- **补天**：国内知名漏洞平台
- **漏洞盒子**：国内平台

## 三、学习路径

1. ⬜ Web 安全基础（SQL注入、XSS、CSRF）
2. ⬜ OWASP Top 10
3. ⬜ 信息收集与侦察
4. ⬜ 常见漏洞挖掘技巧
5. ⬜ 漏洞报告撰写

## 四、常用工具

- Burp Suite
- Nmap
- Dirsearch / Gobuster
- Wappalyzer
