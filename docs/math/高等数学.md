# 高等数学

## 一、函数与极限

### 1. 函数的概念

设数集 $D \subset \mathbb{R}$，则映射 $f: D \to \mathbb{R}$ 称为定义在 $D$ 上的函数，记作 $y = f(x)$。

### 2. 极限的定义

$\lim_{x \to x_0} f(x) = A$ 的 $\varepsilon$-$\delta$ 定义：

> 对于任意给定的 $\varepsilon > 0$，总存在 $\delta > 0$，使得当 $0 < |x - x_0| < \delta$ 时，有 $|f(x) - A| < \varepsilon$。

### 3. 重要极限

$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

$$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e$$

### 4. 等价无穷小（x → 0 时）

| 函数 | 等价无穷小 |
|------|-----------|
| $\sin x$ | $x$ |
| $\tan x$ | $x$ |
| $\arcsin x$ | $x$ |
| $\arctan x$ | $x$ |
| $1 - \cos x$ | $\frac{1}{2}x^2$ |
| $e^x - 1$ | $x$ |
| $\ln(1+x)$ | $x$ |
| $(1+x)^\alpha - 1$ | $\alpha x$ |

## 二、导数与微分

### 1. 导数定义

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

### 2. 基本求导公式

| 函数 | 导数 |
|------|------|
| $C$ | $0$ |
| $x^\alpha$ | $\alpha x^{\alpha-1}$ |
| $a^x$ | $a^x \ln a$ |
| $e^x$ | $e^x$ |
| $\log_a x$ | $\frac{1}{x \ln a}$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |

### 3. 求导法则

**乘法法则**：$(uv)' = u'v + uv'$

**除法法则**：$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$

**链式法则**：$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$

## 三、积分

### 1. 不定积分基本公式

$$\int x^\alpha dx = \frac{x^{\alpha+1}}{\alpha+1} + C \quad (\alpha \neq -1)$$

$$\int \frac{1}{x} dx = \ln|x| + C$$

$$\int e^x dx = e^x + C$$

$$\int \sin x dx = -\cos x + C$$

$$\int \cos x dx = \sin x + C$$

### 2. 牛顿-莱布尼茨公式

$$\int_a^b f(x) dx = F(b) - F(a)$$

其中 $F'(x) = f(x)$。

## 四、常考题型

### 题型一：求极限

**例题**：求 $\lim_{x \to 0} \frac{\sin 3x}{\sin 5x}$

**解**：利用等价无穷小，$\sin 3x \sim 3x$，$\sin 5x \sim 5x$

$$\lim_{x \to 0} \frac{\sin 3x}{\sin 5x} = \lim_{x \to 0} \frac{3x}{5x} = \frac{3}{5}$$

### 题型二：求导数

**例题**：求 $y = x^2 \sin x$ 的导数

**解**：用乘法法则

$$y' = 2x \sin x + x^2 \cos x$$

### 题型三：求积分

**例题**：求 $\int x e^x dx$

**解**：用分部积分法，设 $u = x$，$dv = e^x dx$

$$\int x e^x dx = x e^x - \int e^x dx = x e^x - e^x + C$$

## 五、学习建议

1. **理解概念**：不要死记硬背，理解极限、导数、积分的几何意义
2. **多做练习**：数学是练出来的，每种题型至少做 10 道
3. **整理错题**：建立错题本，定期复习
4. **公式手册**：把常用公式整理成一张表，随时查阅
